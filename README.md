# MiuWave — Downloads

Real-time speech translation for macOS and Windows.

Download the latest version from **[Releases](https://github.com/vietnguyen1103/miuwave-releases/releases/latest)**:

| Your machine | File |
|---|---|
| Mac Apple Silicon (M1/M2/M3/M4) | `MiuWave_<version>_aarch64.dmg` |
| Mac Intel | `MiuWave_<version>_x64.dmg` |
| Windows 10/11 | `MiuWave_<version>_x64-setup.exe` |

On a Mac, open  → About This Mac → *Chip*: Apple M-series → `aarch64`, Intel → `x64`.

The `.app.tar.gz`, `.sig` and `latest.json` files are used by the built-in auto-updater; you don't need to download them.
The `tts-models-vi` pre-release holds voice models the app downloads on demand.

Found a bug or want a feature? Open an [issue](https://github.com/vietnguyen1103/miuwave-releases/issues).
